# Code de conduite

Sois respectueux, constructif et bienveillant. Pas de spam, pas de publicité,
pas d'agressivité.

Les comportements contraires (harcèlement, insultes, contenu illégal) ne sont
pas tolérés. Les mainteneurs se réservent le droit de modérer les issues, les
PR et les discussions.

Signaler un problème : ouvre une issue ou écris au mainteneur.
