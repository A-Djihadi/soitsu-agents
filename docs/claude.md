# Installer un agent sur Claude

Méthode : Projet.

## Étapes

1. Ouvre Claude, connecte-toi.
2. Dans la barre latérale, clique sur **Projets** puis **Nouveau projet**.
3. Nomme le projet (reprends le nom de l'agent).
4. Dans **Instructions du projet** (ou *Set project custom instructions*),
   colle le prompt de l'agent.
5. Remplace les variables `[...]` par tes infos.
6. Ajoute des fichiers de contexte si besoin (ton offre, tes concurrents).

## Astuce

Les instructions de projet s'appliquent à toutes les conversations du projet :
crée un projet par agent, ou un projet « quotidien » qui regroupe tes agents
préférés et rappelle à Claude de choisir le bon selon ta demande.
