# Installer un agent sur Gemini

Méthode : Gem.

## Étapes

1. Ouvre Gemini (gemini.google.com ou l'app), connecte-toi.
2. Ouvre le **gestionnaire de Gems** (Gems).
3. Clique sur **Nouveau Gem**.
4. Nomme-le et, dans **Instructions**, colle le prompt de l'agent.
5. Remplace les variables `[...]` par tes infos.
6. Enregistre. Ton Gem est disponible à tout moment.

## Note

Les Gems nécessitent un compte Google et, pour certaines fonctions, un
abonnement Google AI Pro/Ultra. Le prompt de base fonctionne aussi dans la
conversation classique.
