# Installer un agent sur ChatGPT

Méthode : GPT personnalisé (Custom GPT).

## Étapes

1. Ouvre ChatGPT, connecte-toi.
2. Dans la barre latérale, clique sur **Explorer les GPT** puis
   **Créer un GPT**.
3. Donne-lui un nom et une description (reprends le nom et la description de
   l'`AGENT.md`).
4. Dans le champ **Instructions**, colle le prompt de l'agent.
5. Remplace les variables `[...]` par tes infos.
6. Enregistre. Ton agent est prêt, accessible depuis « Mes GPT ».

## Astuce

Si le GPT doit « se souvenir » de toi (ton ton, ton marché), ajoute ces infos
dans les Instructions, pas dans chaque message. Tu peux aussi joindre un
fichier de contexte (ex. ton offre, tes concurrents) dans **Configuration**.
