# Installer un agent sur Perplexity

Méthode : Espace (Space).

## Étapes

1. Ouvre Perplexity, connecte-toi.
2. Dans la barre latérale, va dans **Spaces** puis **Créer un espace**.
3. Nomme l'espace et ajoute une description.
4. Dans **Instructions de l'espace** (custom instructions), colle le prompt
   de l'agent.
5. Remplace les variables `[...]` par tes infos.
6. Choisis le modèle si proposé, puis enregistre.

## Note

Les espaces avec instructions personnalisées nécessitent un abonnement Pro.
