# Sécurité

Ce dépôt contient uniquement des prompts et de la documentation. Il ne traite
aucune donnée, n'exécute aucun code et ne contient aucun secret.

## Signaler un problème

Si tu repères un prompt qui pourrait exposer une donnée sensible, un lien
interne ou une information à ne pas partager, merci de le signaler en privé
via GitHub → Security → « Report a vulnerability » (private vulnerability
reporting).

Réponse attendue : sous 7 jours.

## Bonnes pratiques pour toi

- Ne mets **jamais** de clé API, de mot de passe ou de donnée personnelle dans
  un prompt que tu partages.
- Avant de coller un prompt qui contient des données réelles, remplace-les par
  des valeurs génériques entre crochets `[...]`.
